# Friska Örnsköldsvik:s kart-repository

Du har kommit till Friska Örnsköldsviks repository - för administration av kartorna.
Den användarvänliga sidan, publika webbsidan för orienterare, för hämtning av kartor nås: [https://friska-ovik.github.io/kartor](https://friska-ovik.github.io/kartor/)

<br>

## För administratörer

### Struktur

Varje år har en egen mapp, och varje karta för respektive år, har en egen undermapp - där fil(er) för respektive karta ligger.

### Filnamn
Filnamn följer formatet:

FRISKAÅR_KX_Plats.tif

Detta för att orienteraren enkelt skulle kunna identifiera karta/fil på sin handhållna enhet.
Exempelvis heter 2026 års karta 5 över Nävertjäl:

FRISKA26_K5_Navertjal.tif
